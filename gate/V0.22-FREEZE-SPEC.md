# v0.22.0 — Freeze the PRD and the design after hand-off

Extends the existing tamper-evidence (the gate code hashes the 11 *answers*) to
the whole *document* and the *design*. Principle: we **detect** post-hand-off
drift and keep a **frozen snapshot** — we don't hard-lock external tools.

## What gets captured at Ready-Check clear

Add to the hand-off + contract frontmatter:

```yaml
readyCheck: RC-XXX-XXXXXX        # existing — hash of the 11 answers
prdHash:    <sha256 of the generated/source PRD body>
source:     { type: jira|confluence|paste, id: <key/pageId>, version: <n> }
design:     { url: <figma url>, version: <figma version id>, lastModified: <ts> }
```

The gate code's hash input is extended to include `prdHash` + `design.version`,
so a changed PRD **or** a changed design invalidates the code — same as a
changed answer does today.

## PRD immutability (no new connector needed)

1. **Content hash.** Hash the PRD body at clear; store `prdHash`.
2. **Native version pin.** Confluence pages carry `version.number`; JIRA issues
   carry `updated`. Capture in `source.version` (read tools already wired).
3. **Frozen snapshot.** `/contract promote` already commits an immutable
   revision — that file is canonical; the live doc is only compared against it.

**Verify at `/contract pickup`:** re-fetch the source, re-hash / compare
version. Result: `VALID` · `STALE-PRD` (doc drifted → re-run Ready Check).

## Design immutability (needs the Figma connector)

1. **Pin the version.** Figma exposes a file `version` id + `lastModified`.
   Capture at clear; rewrite the design link to a **version-locked URL**
   (`?version-id=…`) so dev always opens the signed-off state.
2. **Named version (best).** Ask the designer to cut a Figma named version
   ("Ready Check sign-off — <date>"); Figma version history is immutable.
3. **Visual snapshot.** Export the referenced `node-id` frames to PNG/PDF at
   clear and attach to the ticket — a frozen picture of what was approved.
4. **Drift-guard.** During the build window, re-read the live `version`; if it
   advanced past the pin, flag `STALE-DESIGN` (a design analogue of
   rollback-guard).

## Pickup verdicts

`/contract pickup` returns one of: `VALID` · `STALE-PRD` · `STALE-DESIGN` ·
`INVALID`. STALE-* stops grooming and asks for a fresh Ready Check.

## Honest limits

- **Detect, not prevent.** Hard prevention means locking JIRA/Confluence/Figma
  permissions — a separate, heavier ask, out of scope here.
- **Figma `lastModified` is noisy** (any nudge bumps it); named versions /
  version pins are the meaningful signal.
- **Design freeze depends on the Figma connector** being authorized.

## Build order

1. `prdHash` + Confluence/JIRA `source.version` capture + pickup verify
   (no new connector) — ship first.
2. Design version pin + snapshot + drift-guard — after Figma is connected.
